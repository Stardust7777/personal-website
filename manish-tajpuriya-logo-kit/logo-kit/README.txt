MANISH TAJPURIYA — LOGO KIT
============================

WHAT'S INSIDE
  svg/   Vector source files (scale to any size, editable in Illustrator/Figma/Inkscape)
  png/   Rasterized exports at common sizes

FILES

  icon-transparent-dark / -light
      The mark alone, no background. Use "-dark" (navy letters) on light
      pages, "-light" (white letters) on dark/photo backgrounds.

  icon-square-dark / -light
      Rounded-square app-icon style. Good for: app icons, GitHub avatar,
      LinkedIn/profile photo, favicons that need a filled background.

  icon-circle-dark / -light
      Same mark in a circle badge. Good for: Twitter/X avatar, circular
      profile photos, stamp-style use on a CV or business card.

  favicon.svg / png/favicon/*
      Simplified version (orbit ring dropped) so it stays legible down
      to 16x16. Use favicon-32 or favicon-16 for browser tabs,
      favicon-180 for Apple touch icon, favicon-192/512 for web app icons.

  wordmark-horizontal-light / -dark
      Full lockup: mark + "MANISH TAJPURIYA" + "AEROSPACE ENGINEER".
      Use for letterhead, email signature, website header, CV footer.

SIZES PROVIDED (png/)
  Icons: 1024, 512, 256, 128, 64, 32 px
  Favicon: 512, 192, 180, 64, 48, 32, 16 px
  Wordmark: 1800px and 900px wide

USAGE NOTES
  - SVGs scale losslessly — prefer them for web (favicon.ico generation,
    <img> tags) and for print.
  - Navy: #0b1526 / #16233f   Accent blue: #2f6fed (light bg) / #7fa8ff (dark bg)
  - Keep clear space around the mark roughly equal to the width of the
    "M" stem when placing next to other logos or text.
